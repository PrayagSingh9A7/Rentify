# 🏠 Rentify

A modern full-stack rental platform that helps users discover verified rental properties across India with intelligent search, real-time communication, AI-powered recommendations, and a premium user experience.

---

## 🚀 Features

### 🔐 Authentication & Authorization

- JWT-based secure authentication
- User Registration & Login
- Protected Routes
- Role-based Access (Tenant & Property Owner)

### 🏡 Property Management

- Add, Edit & Delete Properties
- Property Image Gallery
- Property Details & Amenities
- Availability Status
- Wishlist / Saved Properties
- Featured Listings

### 🔍 Smart Property Search

- Search by City & Locality
- Advanced Property Filters
- Budget Filtering
- Property Type Filtering
- Furnishing Filters
- Gender Preference Filters
- Sort by Price & Ratings

### 💬 Real-Time Communication

- Tenant ↔ Owner Chat
- Socket.IO Powered Messaging
- Instant Notifications

### ⭐ Reviews & Ratings

- Property Reviews
- Rating System
- Anonymous Reviews
- Review Analytics

### 🤖 AI-Powered Features

- AI Locality Advisor
- AI Monthly Expense Predictor
- AI Property Recommendation System
- Personalized Rental Suggestions

### ❤️ User Experience

- Save Properties
- Recently Viewed Properties
- Responsive Design
- Premium Glassmorphism UI
- Smooth Animations with Framer Motion
