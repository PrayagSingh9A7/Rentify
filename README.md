\# rentify 🏠



Modern full-stack rental platform for discovering PGs, flats, studios and roommate-friendly stays with realtime chat, AI-powered recommendations and premium user experience.



\---



\## ✨ Features



\### 🔐 Authentication



\* JWT-based authentication

\* Login / Register

\* Protected routes

\* Role-based access (Tenant / Owner)



\### 🏘 Property Listings



\* Add / Edit / Delete properties

\* Featured listings

\* Property image gallery

\* Amenities \& availability

\* Save / Wishlist properties



\### 🔎 Smart Search



\* Advanced filters

\* Budget filtering

\* City \& locality search

\* Furnishing \& gender preference filters



\### 💬 Realtime Chat



\* Tenant ↔ Owner messaging

\* Socket.io powered realtime communication



\### ⭐ Reviews \& Ratings



\* Property reviews

\* Anonymous reviews

\* Ratings system



\### 🤖 AI Features



\* Locality advisor

\* Expense predictor

\* Smart recommendations



\### 🎨 Premium UI



\* Airbnb-inspired modern interface

\* Responsive design

\* Glassmorphism effects

\* Smooth animations with Framer Motion
